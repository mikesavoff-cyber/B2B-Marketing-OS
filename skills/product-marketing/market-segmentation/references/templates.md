## Segment Map

```markdown
# [Company] — Segment Map

**Date**: [YYYY-MM-DD] · **Basis**: [survey / usage data / databases / public sources only]
**Source classes**: (1) directly observed · (2) company's own claim · (3) this skill's judgment

## The call
[One sentence: the segment to lead with, and the one to deprioritize.]

## Segmentation approach
| Factor | Answer | Why it matters here |
|---|---|---|
| B2B or B2C | | |
| Top-down or bottoms-up | | |
| Company stage | | |
| Corporate strategy (disrupt vs. create category) | | |

**Types used:** [e.g. firmographic + technographic + behavioral], because [reason].

## Segments (4 or fewer)

### Segment 1: [Name]
- **Defining attributes:** [attribute: value, source]
- **Estimated size:** [number or range, source]
- **Competitors in this segment:** [from competitor-research, or "not yet checked"]
- **MASA check:**
  - Measurable: [yes/no + how]
  - Accessible: [yes/no + how]
  - Substantial: [yes/no + why]
  - Actionable: [yes/no + overlap with other segments]

[Repeat for segments 2-4]

## Open questions
- [Question]: resolved by [specific evidence]

## Hands off to
- icp-definition: [which segments to prove and prioritize]
- buyer-personas: [which roles sit inside the lead segment]
- account-scoring: [attributes to score on]
```

## Segmentation Survey

Source: *How to Build Segments*. The course assignment is a 15-question survey.

```markdown
# Segmentation Survey — [Company]

## Part 1: Filter questions (structured, agreed by the team)
1. [Firmographic or demographic question, e.g. company size]: [MECE answer options]
2. [Industry / role / region]: [options]
3. ...

## Part 2: Segmentation-type questions (structured)
[For each chosen type, ask questions with structured answers. Psychographic example:
"How would you rate yourself on the following items" on a 1-5 scale.]

## Part 3: Open-ended (sparingly)
[1-3 questions that let customers express their own point of view.]
```

Rules:
- Every answer set is mutually exclusive and collectively exhaustive where possible.
- Prefer structured answers. Free-form answers "maybe don't have explicit patterns."
- "Put in the time here, don't rush yourself."
- Fielding options named in the course: Qualtrics (segmentation guide), centiment.co.
