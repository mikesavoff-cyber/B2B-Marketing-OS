# Taxonomy crosswalk

Four sources classify the same underlying question: how much does the buyer already know, and
what are they comparing you to? Use one as primary. Use the others only for what they add.

## Which taxonomy does what

| Taxonomy | Source | Primary use in this skill |
|---|---|---|
| Category strategy: mature, immature, new | Fletch §1 | The bet in Stage 2. Also sets the game (Fletch §19). |
| Product type: 10x better, new way, vertical solution, buy vs. build | MKT1 guide Step 2 | **Primary.** Produces the comparator and awareness level the statement needs. |
| Demand type: new concept, new paradigm, established category | Dell L4 | Story emphasis in Stage 4: lead with change, with villain, or either. |
| Energy: M1, M2, M3 | `icp-definition` (from "You're building your ICP wrong") | Upstream input. Tells you what the segment is doing today. |

## Approximate mapping

These are the closest matches, not equivalences. Where a row has "no match," the sources don't
cover that combination.

| MKT1 product type | Fletch strategy | Dell demand type | Likely M-type | Comparator (MKT1) | Awareness (MKT1) |
|---|---|---|---|---|---|
| 10x better | Mature category | Established category | M3 | Current category leaders | Problem aware, solution aware |
| New way | Immature or new category | New concept or new paradigm | M1 or M2 | The old combination of tools, services, processes | Rarely problem aware, not solution aware |
| Vertical solution | Mature or immature (depends on the horizontal category) | No match; usually new paradigm | M2 or M3 | Horizontal tool not built for this audience | Usually problem aware, not solution aware |
| Buy vs. build | Immature | New paradigm ("retools an existing process," Dell L4) | M2 | Building and running it internally | Usually problem aware, rarely solution aware |

## Rules from the sources

- **Stuck between vertical solution and new way:** choose vertical solution (MKT1 guide Step 2).
- **Stuck between buy vs. build and new way:** choose buy vs. build (MKT1 guide Step 2).
- **No product type fits:** the product isn't differentiated, or the audience is too broad.
  Narrow the audience first (MKT1 guide Step 2).
- **New way or immature category:** position against the old way, not early competitors
  (MKT1 guide; MKT1 Complete §12 principle 1; Fletch §1 strategy 2).
- **Demand type sets story emphasis (Dell L4, L5):** new concept leads with change and stakes.
  New paradigm leads with a strong villain. Established category can use either.
- **Game (Fletch §19):** mature and 10x better is usually the stand-out game. New way and
  immature category is usually the education game. Say which one explicitly in the strategy
  memo. It changes every downstream channel decision.
- **Category existence test (Fletch §1):** ask an LLM for the top five vendors in the category.
  A clear ranked list means the category exists. Run it and record the answer.
- **Product type changes over time (MKT1 guide).** Record today's type and the likely next one.

## Mismatch flags

Stop and show Mike when:
- The ICP's M-type and the product type point to different comparators (for example, M3
  segment but new way product type).
- Dell's nine demand-type questions (L4) give a different answer than MKT1's product type.
- The market category label chosen in Stage 3 implies a different strategy than Stage 2.
